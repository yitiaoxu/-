# 初赛作品要求与评分细则



## 1、作品提交要求

- 技术文档：提交Word版本及PDF版本各一份，正文内容包括系统总体设计方案、硬件架构图、算法流程图、核心代码注释、仿真与测试报告（含测试数据、指标分析）。<span style="color:red">建议封面和目录后的第1-2页作为重要内容预览页</span>。
- 演示视频：MP4格式、1080p、横屏、3min以内、包含系统搭建说明、功能演示、关键指标测试过程
- 技术数据：提交一份打包的压缩包文件，内容包括**硬件逻辑代码**、**仿真脚本**、**上位机控制代码**，需要**注明开发工具与版本**



## 2、评分标准

| 内容       | 分值 | 要求                                                         |
| ---------- | ---- | ------------------------------------------------------------ |
| 基础要求   | 20   | 完成视频的采集输入、识别、输出整个链路（:white_check_mark:） |
| 加分项     | 15   | 对车牌进行识别，并对车牌进行标记，针对不同场景下一个或者多个车牌进行标记，标记准确率越高得分越高 |
|            | 15   | 不同角度及光线强度下识别准确率，识别率越高得分越高           |
|            | 10   | 特殊车牌识别（1种5分、2种7分、大于三种车牌识别10分）         |
|            | 5    | 创新能力：完成行人识别，并对行人违法行为进行标记....         |
|            | 15   | 识别延迟、系统延迟越低，得分越高                             |
| 设计完整性 | 3    | 完整仿真报告                                                 |
|            | 3    | 完整功耗、时序、面积、性能测试与展示报告                     |
|            | 3    | 完整设计方案                                                 |
