### rgb565_to_rgb888_local()*

- 把一段 RGB565 格式的图像像素数据，转换成 RGB888 格式。
- 输入是 `image565`（每个像素 16 位），输出到 `image888`（每个像素 3 字节：R/G/B 各 8 位）。

```
void rgb565_to_rgb888_local(const uint16_t *image565, uint8_t *image888, size_t num_pixels) {
    for (size_t i = 0; i < num_pixels; ++i) {
        uint16_t pixel = image565[i];
        uint8_t r = ((pixel >> 11) & 0x1F) << 3;
        uint8_t g = ((pixel >> 5) & 0x3F) << 2;
        uint8_t b = (pixel & 0x1F) << 3;
        image888[3 * i] = r;
        image888[3 * i + 1] = g;
        image888[3 * i + 2] = b;
    }
}
```



### InferenceThread::InferenceThread/~InferenceThread()*

InferenceThread的构造函数和析构函数，

构造函数：

1) 初始化列表先执行

```
: QThread(parent), keep_running(false), current_input_type(INPUT_CAMERA),

  camera_index(0), yolo11_detector(nullptr), yolo11_thread_pool(nullptr), lprnet_ready(false)
```

这里在进入 `{}` 前完成基础状态设置：

- 调用父类 `QThread(parent)`，把这个对象作为 Qt 线程对象正确构造。
- `keep_running(false)`：线程初始不跑，避免刚创建就进入循环。
- `current_input_type(INPUT_CAMERA)`：默认输入源设为摄像头。
- `camera_index(0)`：默认摄像头索引 0。
- `yolo11_detector(nullptr)` / `yolo11_thread_pool(nullptr)`：指针先置空，保证后续析构里可安全判空删除。
- `lprnet_ready(false)`：LPRNet 默认未就绪，只有初始化成功才置 `true`。

2) 设置模型路径与线程数

std::string yolo_model_path = "./weights/yolov11_3568.rknn";

std::string lprnet_model_path = "./weights/lprnet_rk3568.rknn";

int numThreads = 4;

作用是准备后续加载参数：

- YOLO 检测模型路径
- 车牌识别模型路径
- YOLO 线程池工作线程数

3) 初始化 YOLO 检测器 + 线程池

yolo11_detector = new Yolov11Custom(); 

if (yolo11_detector->LoadModel(yolo_model_path.c_str()) == NN_SUCCESS) {

​    yolo11_thread_pool = new Yolov11ThreadPool();

​    yolo11_thread_pool->setUp(yolo_model_path, numThreads);

}

逻辑含义：

- 先创建单个检测器对象 `Yolov11Custom`。
- 尝试加载 YOLO 模型，只有加载成功（`NN_SUCCESS`）才继续：
  - 创建 `Yolov11ThreadPool`
  - 用同一个模型路径 + 线程数初始化线程池

也就是：线程池依赖模型加载成功，失败就不建池，避免无效资源占用或后续崩溃。

4) 初始化 LPRNet 上下文

memset(&lprnet_ctx, 0, sizeof(rknn_app_context_t));

if (init_lprnet_model(lprnet_model_path.c_str(), &lprnet_ctx) == 0) {

​    lprnet_ready = true;

}

先把 `lprnet_ctx` 清零，防止脏数据；然后尝试加载 LPRNet：

- 返回 0 表示初始化成功 -> `lprnet_ready = true`
- 否则保持 `false`，表示车牌识别功能不可用或未就绪

析构函数：

1) 先停线程，再做资源释放

stop();

wait();

这两步非常关键：

- `stop()`：通知线程退出主循环
- `wait()`：阻塞等待线程真正结束

为什么先做这个？因为线程还在跑时就删模型/线程池，会出现并发访问已释放内存的问题（高风险崩溃）。

2) 释放 YOLO 检测器对象

if (yolo11_detector) { delete yolo11_detector; yolo11_detector = nullptr; }

判空后删除，删除后置空，避免悬空指针。

3) 停止并释放 YOLO 线程池

if (yolo11_thread_pool) {

​    yolo11_thread_pool->stopAll();

​    delete yolo11_thread_pool;

​    yolo11_thread_pool = nullptr;

}

这里比普通 `delete` 多一步 `stopAll()`，说明线程池内部可能还有工作线程，需要先停干净再释放对象。

4) 释放 LPRNet 模型资源

if (lprnet_ready) {

​    release_lprnet_model(&lprnet_ctx);

​    lprnet_ready = false;

}

只有在成功初始化过时才释放，避免对未初始化上下文做无效释放。

### QString InferenceThread::detectPlateColor(**const** cv::Mat**&** plate_img)*

```
QString InferenceThread::detectPlateColor(const cv::Mat& plate_img) {
    if (plate_img.empty()) return "Unknown";
    cv::Mat hsv, mask_b, mask_y, mask_g;
    cv::cvtColor(plate_img, hsv, cv::COLOR_BGR2HSV);
    cv::inRange(hsv, cv::Scalar(100, 50, 50), cv::Scalar(124, 255, 255), mask_b);
    cv::inRange(hsv, cv::Scalar(15, 50, 50), cv::Scalar(34, 255, 255), mask_y);
    cv::inRange(hsv, cv::Scalar(35, 50, 50), cv::Scalar(85, 255, 255), mask_g);

    int b_pts = cv::countNonZero(mask_b);
    int y_pts = cv::countNonZero(mask_y);
    int g_pts = cv::countNonZero(mask_g);
    int max_pts = std::max({b_pts, y_pts, g_pts});
    
    if (max_pts < 50) return "Unknown";
    if (max_pts == b_pts) return "蓝色";
    if (max_pts == y_pts) return "黄色";
    return "绿色";
}
基于 HSV 阈值的颜色分类函数
```

把车牌图转 HSV 后分别做蓝/黄/绿掩码统计，哪个像素点最多就判成哪种颜色；像素太少（`max_pts < 50`）返回 `Unknown`，返回一个字符串

### InferenceThread::drawChineseTextAndBox(cv::Mat**&** img, **const** cv::Rect**&** box, **const** QString**&** text, **const** cv::Scalar**&** color)*

```
void InferenceThread::drawChineseTextAndBox(cv::Mat& img, const cv::Rect& box, const QString& text, const cv::Scalar& color) {
    cv::Mat rgb;
    cv::cvtColor(img, rgb, cv::COLOR_BGR2RGB);
    QImage qimg(rgb.data, rgb.cols, rgb.rows, rgb.step, QImage::Format_RGB888);
    QPainter painter(&qimg);
    painter.setRenderHint(QPainter::Antialiasing);
    QColor qColor(color[2], color[1], color[0]); 
    
    painter.setPen(QPen(qColor, 3));
    painter.drawRect(box.x, box.y, box.width, box.height);
    QFont font("Microsoft YaHei", 18, QFont::Bold);
    painter.setFont(font);
    QFontMetrics fm(font);
    
    int w = fm.horizontalAdvance(text), h = fm.height();
    painter.setBrush(qColor);
    painter.setPen(Qt::NoPen);
    painter.drawRect(box.x, box.y - h - 8, w + 10, h + 8);
    painter.setPen(QColor(0, 0, 0)); 
    painter.drawText(box.x + 5, box.y - 5, text);
    painter.end();
    cv::cvtColor(rgb, img, cv::COLOR_RGB2BGR);
}
图片加工，在原始的图片上添加画框、文本
```

- 在一帧 OpenCV 图像 `img` 上，给检测框 `box` 画框；
- 在框上方画一个彩色文字底条；
- 在底条里绘制中文文本 `text`（比如“蓝色 京A12345”）；
- 最后把结果写回原图 `img`。



### InferenceThread::run()*

```
void InferenceThread::run() {
    if (!yolo11_detector || !yolo11_thread_pool || !lprnet_ready) {
        emit showMessage("模型初始化失败");
        return;
    }
    keep_running = true;
    ensureOutputDirectory(); //确保输出目录存在

//按照输入源分发处理逻辑
	//图片
    if (current_input_type == INPUT_IMAGE) processSingleImage();
    //PCIe
    else if (current_input_type == INPUT_PCIE) processPCIeStream();
    //其它（摄像头/视频）
    else processStream();
    
    emit showMessage("就绪");//处理完后发送“就绪”消息
}
```



### InferenceThread::processPCIeStream()*PCIe图像输出



```
void InferenceThread::processPCIeStream() {
    std::cout << "\n[PCIe] 尝试打开设备节点..." << std::endl;
    int fd = -1;
    const char* used_node = nullptr;
    const char* pcie_nodes[] = {
        "/dev/pango_pci_driver",
        "/dev/xdma0_c2h_0",
        "/dev/input/event0",
        "/dev/input/event8"
    };

    for (const char* node : pcie_nodes) {
        fd = open(node, O_RDWR);
        if (fd >= 0) {
            used_node = node;
            break;
        }
    }
    if (fd < 0) {
        std::cerr << "[PCIe] 错误: 无法打开设备节点，errno="
                  << errno << " (" << std::strerror(errno) << ")" << std::endl;
        emit showMessage("无法打开 PCIe 设备");
        return;
    }
    std::cout << "[PCIe] 设备节点打开成功: " << used_node << std::endl;
```

根据定义的节点数组，一次对节点进行打开操作，如果成功打开则记录成功节点，并退出循环，用于打开PCIe的设备节点。如果列表中的节点都无法打开则报错。

```
typedef struct _DMA_OPERATION_ {
    unsigned int current_len; //当前 DMA 传输长度（一次操作要传多少数据）
    unsigned int offset_addr;//偏移地址（本次 DMA 操作的地址偏移）
    unsigned int cmd;//命令字段（用于区分具体 DMA 操作命令）
    DMA_DATA data;//具体数据区（读写缓冲等），类型是另一个结构体 DMA_DATA
} DMA_OPERATION;
```

**result_cnt = 0//以取回结果数, **

此处说明`ioctl(fd, PCI_MAP_ADDR_CMD, &dma_operation)`

- `PCI_MAP_ADDR_CMD`（编号 2）
  - 开始一轮 DMA 前的“映射/准备”命令
  - 常用于让驱动建立地址映射或准备访问上下文
- `PCI_DMA_WRITE_CMD`（编号 5）
  - 触发一次 DMA 传输动作
  - 在你的循环里每行都会调用一次，等价于“开始搬这一行数据”
- `PCI_READ_FROM_KERNEL_CMD`（编号 6）
  - 从驱动/内核缓冲区把数据取回到用户态结构体里
  - 你的代码随后 `memcpy` 到整帧缓存
- `PCI_UMAP_ADDR_CMD`（编号 7）
  - 一轮传输结束后的“取消映射/收尾”命令
  - 用于释放映射或清理状态

**逐行把设备侧（DDR 数据）搬到 ARM 端用户态原始缓存 `image_buf_temp`**

```
            ioctl(fd, PCI_MAP_ADDR_CMD, &dma_operation);//开始本轮 DMA 读取前的准备动作
            for (int i = 0; i < height; i++)//按行读取图像数据
            {
                memset(dma_operation.data.read_buf, 0, DMA_MAX_PACKET_SIZE);//清空本次接收缓存，避免脏数据
                ioctl(fd, PCI_DMA_WRITE_CMD, &dma_operation);//出发一次DMA传输动作
                for (volatile int k = 0; k < 2500; k++); //短延时，等硬件/驱动准备好数据
                ioctl(fd, PCI_READ_FROM_KERNEL_CMD, &dma_operation);//把这一行数据从内核侧读到 dma_operation.data.read_buf
                memcpy(image_buf_temp.data() + i * 2560, dma_operation.data.read_buf, 2560);//拷贝到整帧缓存对应行位置
            }
            ioctl(fd, PCI_UMAP_ADDR_CMD, &dma_operation);//本帧读完后做收尾，释放/取消映射资源
```

```
    yolo11_thread_pool->submitTask(frame.clone(), 0);//把当前图片提交到 YOLO 线程池，任务ID设为0用 clone() 做深拷贝，避免原图被后续操作影响

    while (yolo11_thread_pool->getTargetResultNonBlock(objects, 0) != NN_SUCCESS && keep_running) {
        usleep(1000);
    }//非阻塞轮询等待任务0的结果

    if (!keep_running) return;//如果等待过程中被要求停止，就直接退出，不再继续后处理
```
